# 业务说明（business）

本目录存放**按业务能力**拆分的说明，供改功能时按需加载；与根下工程约束文档分工如下：

| 类型 | 位置 | 内容 |
|------|------|------|
| 工程 / 分层 / 构建 | `docs/*.md`、`AGENTS.md` | 怎么写代码、怎么编译 |
| **业务** | **`docs/business/*.md`** | 业务做什么、涉及哪些类、路径、关键 API |

## LLM / Agent 加载方式

1. 先读 [`../README.md`](../README.md) 本表，确认业务文档 id。  
2. **只打开与当前任务相关的** `docs/business/<id>.md`，不要一次读完所有业务文。  
3. 改代码前再用搜索核对类/文件是否与文档一致；文档与代码冲突时以代码为准并回写本文档。
